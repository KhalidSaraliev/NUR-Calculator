# NUR Invest

В репозитории два проекта:

- **`web/`** — новый сайт NUR Invest на Next.js: главная, каталог, калькулятор, заявки, админ-панель,
  подготовленная интеграция онлайн-оплаты. Запуск и настройка — в [web/README.md](web/README.md).
- **корень (`index.html`, `css/`, `js/`, `img/`)** — исходный статичный калькулятор. Оставлен без изменений
  и работает как раньше. Таблица наценок из него перенесена в `web/src/config/terms.ts`.

> В исходном калькуляторе есть формулировки «По нормам шариата» и «Ответ за 5 минут».
> До документального подтверждения их лучше убрать — на новом сайте они не используются.
